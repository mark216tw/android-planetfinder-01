# 系統設計文件

## 目標

讓一般使用者不需要理解赤經、赤緯或星圖，即可透過熟悉的羅盤和抬高手機動作尋找太陽、月球及行星。

## 非目標

- 不提供精密望遠鏡赤道儀校準。
- 不判斷雲量、建築、山脈或光害遮蔽。
- 不提供星座、深空天體及完整星圖。
- 不執行背景位置追蹤。
- 不保證航海、飛行或其他安全用途的方向精度。

## 功能需求

| 編號 | 需求 |
|---|---|
| FR-01 | 顯示太陽、月球及七大行星 |
| FR-02 | 依位置和時間計算方位角與仰角 |
| FR-03 | 以真北羅盤提供左右轉向提示 |
| FR-04 | 以手機姿態提供抬高與降低提示 |
| FR-05 | 顯示升起、落下、照明比例與視星等 |
| FR-06 | 允許收藏星體並在裝置內持久保存 |
| FR-07 | 拒絕定位時仍可使用預設位置 |
| FR-08 | Android 返回鍵遵循頁面歷史 |
| FR-09 | 支援系統淺色與深色主題 |

## 品質需求

- 最低支援 Android 8.0。
- 天文核心功能離線可用。
- UI 計算不得阻塞主執行緒。
- 磁方位需修正為真北。
- 系統列及內容需處理 Edge-to-edge Insets。
- 太陽頁面必須顯示安全警告。

## 畫面設計

### 首頁

顯示目前高度最高的可見星體、尋星入口及所有星體摘要。每張卡片包含符號、名稱、方向、仰角與可見狀態。

### 收藏

只顯示已收藏星體；空狀態引導使用者由資訊頁加入收藏。

### 尋星

由羅盤、目標方位、目標仰角、手機仰角及目標切換選單組成。低於地平線的星體顯示下一次升起時間。

### 星體資訊

提供星體簡介、收藏、尋星入口及今日觀測資料。此頁隱藏 APP 底部導覽列並保留 Android Navigation Bar 安全間距。

## 狀態與錯誤處理

| 情境 | 行為 |
|---|---|
| 尚未完成天文計算 | 顯示載入指示 |
| 未授權定位 | 使用台北預設位置 |
| 定位提供者不可用 | 使用最後位置或台北位置 |
| Rotation Vector 不可用 | 使用加速度計與磁力計 |
| 所需感測器皆不可用 | 持續顯示正在讀取方向感測器 |
| 星體位於地平線下 | 停止對準指引並顯示升起時間 |
| 兩日內無升落事件 | 顯示「兩日內無事件」 |

## 安全設計

- 尋找太陽時顯示醒目的安全警告。
- 不要求網路權限，不上傳位置或收藏。
- 公開 Pre-release 只使用 Debug 簽章，不包含正式金鑰。
- R8 mapping 與建置產物不納入 Git 原始碼提交。

## 未來方向

- 天文事件與通知。
- 無磁力計裝置的明確錯誤狀態。
- UI 與返回導覽的儀器測試。

# 第三方套件

本專案使用下列主要開放原始碼軟體。實際依賴及傳遞依賴以 Gradle 解析結果為準，各套件仍受原作者的授權條款約束。

| 套件 | 用途 | 授權 |
|---|---|---|
| [Kotlin](https://github.com/JetBrains/kotlin) | 程式語言與標準函式庫 | Apache License 2.0 |
| [AndroidX](https://github.com/androidx/androidx) | Activity、Lifecycle 及 Android 相容元件 | Apache License 2.0 |
| [Jetpack Compose](https://developer.android.com/compose) | 宣告式 UI | Apache License 2.0 |
| [Material Components](https://github.com/material-components/material-components-android) | Material 3 設計元件 | Apache License 2.0 |
| [Astronomy Engine](https://github.com/cosinekitty/astronomy) | 太陽、月球與行星位置計算 | MIT License |
| [JUnit 4](https://github.com/junit-team/junit4) | 單元測試 | Eclipse Public License 1.0 |

發行或再散布應用程式前，維護者應再次檢查完整依賴樹及對應授權文件。

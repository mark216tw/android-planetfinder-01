# 使用指南

## 安裝

1. 從 GitHub Releases 下載 `app-prerelease.apk`。
2. 在 Android 裝置允許瀏覽器或檔案管理器安裝未知來源應用程式。
3. 開啟 APK 並完成安裝。

Pre-release 使用 Debug 金鑰簽署，只適合測試。若相同套件名稱已由其他金鑰簽署，需先解除安裝舊版本。

## 首次使用與定位

APP 首次使用時以台北座標計算天空位置。點選畫面上方的位置標籤可選擇：

- 精確定位：優先使用 GPS 或可用的位置提供者。
- 大約位置：計算結果可能有較大誤差。
- 台北、東京或新加坡快速位置。
- 自訂位置名稱、緯度及經度。
- 拒絕權限：繼續使用目前已保存的位置。

位置標籤會顯示「預設位置」、「裝置定位」或「手動位置」。APP 會保存最後使用的位置，但不會在背景持續追蹤。

## 首頁

首頁顯示目前高度最高的可見星體，以及太陽、月球和七大行星的即時方位與仰角。月球與行星會顯示今晚的可觀測性評級、最佳區間及首要原因；太陽顯示「需濾鏡」及當地白天時段。點選任一星體可查看詳細資料。

時間控制可切換回「現在」、向前或向後一小時，或快速查看今晚 20:00。模擬模式中的羅盤目標代表指定時間的天空位置。

點選首頁的「用羅盤尋找」可直接開啟目前建議星體的尋星頁。從尋星頁點選底部「今晚」會返回今晚主畫面，並保留目前選擇的即時或模擬時間。

## 星體資訊

資訊頁包含：

- 即時方位角與仰角。
- 下一次升起與落下時間。
- 照明比例與視星等。
- 星體簡介及收藏按鈕。
- 月球與行星在今晚 18:00 至隔日 06:00 的仰角曲線、暮光背景、最高點與最佳連續區間。
- 太陽在當地日出至日落的白天仰角曲線與最高點。
- 推薦、普通、困難或不可見的評級、主要原因及器材建議。

點選時間軸上的任一位置，整個 APP 會切換到該模擬時間，讓首頁與尋星頁顯示當時的天空。點選「回到現在」可恢復即時模式。夜間時間軸背景由亮至暗分別代表日光、民用暮光、航海暮光、天文暮光與完整暗夜。

可觀測性會考量幾何仰角、暮光、星體亮度、與太陽的角距及明亮月球的干擾，但不包含雲量、光害、地形或建築遮蔽。

點選「用羅盤尋找」可進入尋星頁。Android 返回鍵會回到上一個畫面。

## 尋找星體

1. 遠離大型金屬、磁鐵、車輛及高功率電器。
2. 必要時以 8 字形移動手機校準磁力計。
3. 將手機頂端朝向目標方向。
4. 依畫面提示向左或向右轉動。
5. 依「再抬高」或「再降低」提示調整手機仰角。
6. 方位與仰角誤差都小於約 3° 時，畫面顯示「已對準」。
7. 對準時手機會短暫震動一次。

羅盤的東、西、南、北代表真實地理方向，並會隨手機轉動。手機頂端朝東時，「東」會移到羅盤上方；星體箭頭表示目標相對於手機前方的位置。

尋星頁會顯示感測器精度。若精度偏低或不可靠，請遠離磁性物品並以 8 字形移動手機；若裝置缺少所需感測器，APP 會明確顯示無法使用羅盤導引。

若星體在地平線下，APP 會顯示下一次升起時間，不提供對準指引。

## 收藏

在星體資訊頁點選愛心可加入或移除收藏。收藏資料只保存在目前裝置。

## 太陽安全

切勿直視太陽。羅盤只用於判斷方向，不代表可以安全觀看太陽。望遠鏡、相機及雙筒望遠鏡必須使用合格且正確安裝的太陽濾鏡。

更多背景知識與時間軸判讀方式請參閱[天文與尋星知識教學](ASTRONOMY_GUIDE.md)。

## 疑難排解

### 方向持續偏移

- 移除磁性手機殼。
- 離開金屬桌面、車輛或大型電器。
- 重新校準手機磁力計。
- 確認系統定位及感測器功能正常。

### 仰角不合理

- 保持直向持握，並以手機頂端作為瞄準方向。
- 緩慢移動，等待平滑後的讀值穩定。
- 部分低階裝置的姿態感測器精度有限。

### 星體位置與實際不同

- 點選位置標籤更新目前位置。
- 確認手機日期、時間與時區設定正確。
- 天候、地形與建築遮蔽不會反映在可見狀態中。
